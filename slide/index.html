Path Selection04
Focus05
重点进入

路径2：AI Coding + 微信云开发

AI 负责拆任务、写代码、修报错；微信云开发负责数据库、云函数、文件存储、登录；设计师负责产品定义和体验验收。

Storage Strategy

素材和数据怎么放

短期验证：小量素材轻处理

少量图片、演示视频、原型素材，可以先放 GitHub 仓库，适合早期验证和内部测试。

长期运营：大量音视频进云端

大量视频、音频、课程文件、用户上传内容，更适合放微信云开发存储或对象存储。

成本提醒：微信云开发涉及资源计费，正式上线前要估算存储体积、访问流量、云函数调用和长期成本。

Flow07
总流程

从想法到上线，AI Coding 分成八步

01
定义 MVP用户、目标、页面、功能、不做清单。
02
画页面原型首页、列表页、详情页、我的页。
03
AI 拆任务页面结构、数据表、开发顺序。
04
准备上线资料先记录主体、类目、AppID 等发布前置项。
05
创建项目微信开发者工具中建立工程。
06
Mock 跑通先不接数据库，把页面跳转跑通。
07
接入云开发数据库、登录、收藏、提交、存储。
08
审核发布真机测试、上传代码、提交审核。
Execution Map07
MVP08
产品定义及节奏

第一版功能必须收窄

Do

第一版只做这些

  • 1首页、列表页、详情页、我的页
  • 2登录、收藏、搜索 / 标签筛选
  • 3云数据库内容管理
  • 4基础空状态、错误状态、加载状态
Do Not

第一版不要做这些

  • —推荐算法、IM 聊天、复杂会员体系
  • —积分系统、复杂后台、多端同步开发
  • —自动化内容抓取、多人协作权限
  • —没有验证前的大规模音视频上传

个人主体 = 不支持小程序内微信收款。
只要未来有可能付费、交易、变现，直接跳过个人，选个体户或企业。

02Payment

Checklist13
审核前

不要让审核
卡在基础问题

  • 1主体和类目匹配，功能不要越界。
  • 2隐私协议配置完整，用户授权说明合理。
  • 3核心路径可访问，必要时提供测试账号。
  • 4无空白页、死链、测试内容、违规营销。
  • 5完成真机测试，不只依赖开发者工具。
